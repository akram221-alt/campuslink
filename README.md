
# CampusLink 🎓

### Never Miss an Event Again!

CampusLink is a student-focused campus event discovery and networking platform designed to connect students, event organizers, and campus communities in one place.

Discover events, connect with people who share your interests, explore opportunities, and stay updated on everything happening around your campus.

## ✨ Features

### 🎉 Event Discovery
- Discover upcoming college events, workshops, hackathons, cultural fests, and seminars.
- Search and filter events by category, date, and interests.
- View event details, venue, schedule, and registration information.
- Bookmark events and manage your personal event calendar.

### 🏢 Organizer Profiles
- Explore clubs, societies, and event organizers.
- View organizer profiles, past events, and achievements.
- Follow organizers to receive updates about upcoming events.

### 👥 Student Community
- Connect with students who share similar interests.
- Discover communities based on skills, hobbies, and career goals.
- Find people attending the same events.

### 📊 Event History & Outcomes
- Explore past events, highlights, photos, and participation statistics.
- View event outcomes, achievements, and feedback.
- Learn from previous events and discover future opportunities.

### 🚀 Opportunities
- Discover internships, competitions, workshops, and student opportunities.
- Find events and activities relevant to your interests and career goals.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/campuslink.git
```

### 2. Navigate to the project folder

```bash
cd campuslink
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal to view the application.

## 🎯 Project Goal

To create a single platform where students can discover campus events, connect with organizers, explore communities, and stay informed about every opportunity—so no student has to say, "I didn't know about that event."
